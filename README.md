# 🚗 CarTech

> Enterprise-система управления автомобильной площадкой дилерского центра.

CarTech — внутреннее приложение для автоматизации процессов работы с автомобилями: приёмка, хранение, предпродажная подготовка, контроль аккумуляторов, выдача автомобилей и аналитика склада.

Проект разрабатывается как pet-project с архитектурой, приближенной к реальным Enterprise-приложениям.

---

# Основные возможности

## Приёмка автомобилей

- регистрация поступления автомобилей;
- создание нескольких автомобилей в рамках одного поступления;
- привязка автомобилей к локациям и площадкам;
- хранение истории поступлений.

## Управление складом

- работа с несколькими локациями;
- работа с площадками внутри локаций;
- поиск автомобилей;
- фильтрация по параметрам;
- контроль текущего местоположения автомобиля.

## Автомобили

- VIN;
- короткий VIN;
- бренд;
- модель;
- цвет;
- жизненный цикл автомобиля;
- история операций.

## Предпродажная подготовка (ПСО)

- контроль прохождения ПСО;
- фиксация выполнения работ;
- изменение состояния автомобиля;
- подготовка автомобиля к выдаче.

## Контроль аккумуляторов

- журнал проверок аккумулятора;
- хранение истории измерений;
- контроль состояния автомобилей.

## Пользователи и доступ

- авторизация;
- роли пользователей;
- разграничение доступа по локациям;
- журналирование действий.

# Запуск проекта

## Установка зависимостей

Из корня проекта:

```bash
npm install
Backend

Генерация Prisma Client:

npx prisma generate --schema apps/backend/prisma/schema.prisma

Запуск backend:

npm run serve:backend
Frontend

Запуск frontend:

npm run serve:frontend
Запуск всего проекта
npm run dev

или:

npx nx run-many -t serve -p frontend,backend --parallel=2
Принципы разработки

В проекте используются следующие правила:

DTO используются как публичные API-контракты.
Prisma модели не возвращаются напрямую наружу.
Бизнес-логика находится внутри сервисов.
Изменения базы выполняются только через Prisma migrations.
Сложные операции выполняются внутри транзакций.
Доменные решения фиксируются в документации.
Архитектурные изменения выполняются небольшими независимыми шагами.
