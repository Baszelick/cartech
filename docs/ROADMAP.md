# Цель проекта

CarTech — внутренняя система для технического отдела автодилера.

Главная цель MVP — дать техникам простой и быстрый инструмент для работы с автомобилями:

- приёмка автомобилей;
- выполнение ПСО;
- контроль проверки аккумуляторов;
- выдача автомобилей;
- просмотр текущих задач.

Приоритет проекта:

1. Стабильный Backend
2. Полный Swagger
3. Frontend
4. Расширение функциональности

# Правила разработки

При разработке проекта придерживаемся следующих принципов:

- Backend важнее Frontend.
- Каждый модуль доводится до рабочего состояния перед переходом к следующему.
- Новая функциональность сопровождается Swagger.
- Все API строятся вокруг актуальной Prisma Schema.
- Сложные задачи разбиваются на небольшие независимые этапы.
- Не выполнять масштабные рефакторинги без необходимости.
- После завершения каждого этапа проект должен успешно собираться и проходить тесты.

## 1.3 Cars Module

Самый большой модуль проекта.

Текущее состояние: `GET /cars`, `GET /cars/:id` и
`POST /cars/:id/battery-check` мигрированы на актуальную Prisma Schema.
Финальная проверка этих endpoint заблокирована legacy-кодом PSO, выдачи и задач,
